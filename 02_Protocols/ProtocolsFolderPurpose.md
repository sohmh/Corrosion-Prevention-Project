## 📁 02_Protocols/

| Element | Detail |
| :--- | :--- |
| **Purpose** | To store all **Standard Operating Procedures ($\text{SOPs}$) and Design Documents** that detail *how* the experiments are physically executed. This ensures consistency and reproducibility across all test runs. |
| **Key Role** | Provides the specific, step-by-step instructions necessary to set up the lab, prepare solutions accurately, handle samples, and run measurements exactly the same way every time. |
| **Example Contents** | • $\text{Design \& Sketch}$: $\text{Corrosion Chamber}$ Layout (Task: *Design \& Sketch*)<br>• Sample Cleaning/Preparation $\text{SOP}$<br>• Solution Concentration Calculation Sheets<br>• $\text{Setup \& Sealing}$ Checklist $\text{SOP}$<br>• End-of-Experiment Sample Stripping Protocol |
| **Related Tasks** | $\text{Setup}$, $\text{Preparation}$, $\text{Methodology}$ |
