## 📁 03_Data/Raw/

| Element | Detail |
| :--- | :--- |
| **Purpose** | To store **unmodified, primary data** taken directly from the lab. This is the definitive, "read-only" record of all measurements. **This data must NEVER be edited after recording.** |
| **Key Role** | Ensures data integrity and provides an auditable baseline. Any errors or changes found during analysis must be corrected in the `Processed/` folder, not here. |
| **Example Contents** | • $\text{Initial Masses}$ ($\mathbf{M_{\text{initial}}}$) $\text{CSV}$ (Task: *Sample Preparation*)<br>• $\text{Initial Environment Log}$ ($\text{pH/Temp}$ baseline) $\text{CSV}$ (Tasks: *Solution Preparation*)<br>• Daily $\text{Observation Log}$ (Daily template) $\text{CSV}$ (Task: *Data Logging*)<br>• Any directly exported raw instrument files. |
| **Related Tasks** | $\text{Sample Preparation}$, $\text{Solution Preparation}$, $\text{Data Logging}$ |
