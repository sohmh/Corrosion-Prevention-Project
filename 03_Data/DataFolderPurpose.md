## 📁 03_Data/

| Element | Detail |
| :--- | :--- |
| **Purpose** | To serve as the **central, immutable hub for all experimental measurements and observations**. Data is separated into Raw (unprocessed) and Processed (calculated) states to maintain scientific integrity. |
| **Key Role** | This folder contains the **evidence** and quantitative results of the entire project. It is the definitive record of all measured parameters and observed phenomena. |
| **Subfolders** | **`Raw/`**: Stores data directly from measurements (no calculations applied). **`Processed/`**: Stores files with calculated values (e.g., mass loss, average $\text{pH}$). **`Photos/`**: Stores all image evidence. |
| **Example Contents** | • $\text{Initial Masses}$ ($\mathbf{M_{\text{initial}}}$) $\text{CSV}$ (in **Raw/**)<br>• Daily $\text{Observation Log}$ ($\text{pH, Temp, Visuals}$) (in **Raw/**)<br>• $\text{Weekly Visual Documentation}$ images (in **Photos/**)<br>• $\text{Final Corrosion Rate}$ calculation table (in **Processed/**) |
| **Related Tasks** | $\text{Data Logging}$, $\text{Sample Measurement}$, $\text{Visual Documentation}$ |
